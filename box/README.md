# Example box

This is a starting example for basic project configuration. Its instruction templates contain
generic rules. Review them before using them.

KitFlow downloads this example into `~/.config/kitflow/default/` on first use. Put your overrides in
`~/.config/kitflow/`. Run `kitflow upgrade` to refresh only the standard layer. Keep a backup of
your overrides. Define wizard steps and recommendations in `kitflow-box.toml`.

See [the user instructions](../docs/INSTRUCTION.md) and [the format reference](../docs/CATALOG.md).
