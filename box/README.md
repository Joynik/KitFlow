# Example box

This is a starting example for basic project configuration. Its instruction templates contain
generic rules. Review them before using them.

KitFlow downloads this example once into `~/.config/kitflow/box` on first use. You then own the
local files. Edit and back them up using your preferred tools. KitFlow does not synchronize them
with GitHub afterward.

See [the user instructions](../docs/INSTRUCTION.md) and [the format reference](../docs/CATALOG.md).
